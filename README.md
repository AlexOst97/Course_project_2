# Приложение для работы с сайтом hh.ru

## Цель проекта:

Программа, которая будет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.

## Инструкция по установке:

1. Клонировать с GitHab (*git clone https://github.com/AlexOst97/Course_project_2*)
2. Установить зависимости (*pip install -r requirements.txt*)

## Тестирование проекта

Тестирование функций проекта осуществляется с помощью фреймворка pytest и метрики code coverage.
